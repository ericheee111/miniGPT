Engineering progression

Stage 1–21, compressed

The post-v1 Playground is a deployment extension. It does not rename or extend the completed Stage sequence.

  1. 01–06

    Model + training

    Character tokenizer, Transformer, optimizer, checkpoints, exact resume.

  2. 07–09

    Evidence + inference

    Reference training, mmap batching, explicit KV-cache generation.

  3. 10–12

    Serving control plane

    FIFO ownership, continuous batching, OpenAI-style HTTP and SSE.

  4. 13–15

    Paged KV + APC

    Block lifecycle, direct paged decode, prefix caching and suffix prefill.

  5. 16–18

    Pressure handling

    Chunk budgets, whole-request preemption, lazy KV reservation.

  6. 19

    Runtime policy

    Strict production-facing configuration and deterministic manifests.

  7. 20

    Unified CLI

    Installable commands and an explicit Project Doctor registry.

  8. 21

    v1 closure

    Fresh-install package gates, capstone Evidence, Windows/Linux CI.

Privacy and limitations

A personal systems demo, not a hosted service

Prompts travel from your browser through ngrok to the owner’s local machine. miniGPT does not intentionally log prompts, this page uses no analytics or cookies, and prompts are not saved in localStorage. Do not submit sensitive information.

The backend is available only while the Windows PC and tunnel are running. There is no 24/7 SLA, production-security claim, general-chat capability, or universal performance claim. When compute is offline, this portfolio and its static example remain available.
