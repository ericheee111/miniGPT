    Scope and privacy

    Small model, explicit boundaries

    No 24/7 SLA. Live inference depends on the owner’s local Windows machine and Tailscale Funnel.

    No prompt storage. The public boundary avoids logging full prompts; the browser keeps story history only in memory.

    No general-assistant claim. Generated stories can be repetitive, inconsistent, or nonsensical.

    No universal speedup claim. Systems work is verified for correctness and structure; benchmark verdicts remain separately scoped.
